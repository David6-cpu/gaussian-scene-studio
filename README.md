# Gaussian Scene Studio · 高斯自然场景工作台

**资源库约束的 AI 选材、可复现的程序布局、统一的高斯泼溅渲染。**

A local-first research workbench for asset-guided natural scenes: reviewable LLM selection, deterministic PCG placement, and unified Gaussian splat rendering.

[English](README.en.md) · [本地模型配置](docs/LOCAL_MODELS.md) · [第三方许可](THIRD_PARTY_NOTICES.md) · [SH 导入工具](docs/SH_IMPORT.md)

这是一个大学生创新训练研究原型：把自然语言需求变成可检查的素材选择与场景配方，由程序规则完成摆放，再在浏览器里探索、保存和重开。**当前已验证湿地小场景，通用多环境仍在规划中。**

研究重点是需求约束、候选内选材、缺失处理和布局复现。基础语言模型及扫描资产来自第三方，不宣称自研基础模型或从一句话直接训练出新的三维重建。

## 从想法到场景

```mermaid
flowchart LR
    A[自然语言需求] --> B[结构化与人工审阅]
    B --> C[检索真实资源候选]
    C --> D[LLM 选择候选 ID]
    D --> E[独立校验与人工确认]
    E --> F[PCG 约束布局]
    F --> G[统一 Gaussian 网页渲染]
    G --> H[保存记录与离线场景包]
```

资源不足时会显示缺失；程序素材需要明确确认。模型产生提议，最终应用前仍需检查来源、数量、水位和种子。

## 已有能力

| 能力 | 当前范围 |
|---|---|
| 资源目录 | 7 项登记，其中 4 项试用、3 项用于旧版本兼容；记录来源、许可、实拍/程序身份与点数预算 |
| 两阶段 AI 选材 | 先提取可编辑需求，再从给定候选中选 ID；独立校验，确认后生成 |
| 确定性 PCG | 固定种子复现布局；检查边界、水位、坡度、间距与贴地，报告放不下的数量 |
| 统一 Gaussian 显示 | Riverside 扫描地表与程序低草/芦苇、碎石、静态水面使用同一 Spark 渲染链 |
| 本地保存与重开 | 选材记录、规划版本和自包含场景 ZIP；保留旧文件格式兼容规则 |
| 可选精度工具 | 显式离线 SH3 范围修正与素材包重开；保留原生路径，不自动替换默认素材 |

扫描地表保留 64,949 个 SH3 高斯。当前 Riverside 展示范围为 4×4 **展示单位**，并非实测米制；场景最多 20 个实例、250,000 个活跃高斯。

## 快速体验：不需要模型

需要 Node.js、npm 和支持 WebGL2 的桌面浏览器。已验证环境：Node 25.7.0、npm 11.10.1、macOS / Apple M5 16 GB、Google Chrome；不代表其他平台已完整验收。

在项目根目录运行：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:4173/>。手动调整参数后生成，或在“场景规划与版本”中使用“离线示例”。拖动旋转、右键平移、滚轮缩放；场景 ZIP 可保存后离线重开。

模型权重不在仓库中。没有启动模型时，请使用手动/离线流程；界面显示“默认回退 · 未解释输入”不代表 AI 已理解了描述。

## 使用本地 AI

推荐的已验证路线是 **Qwen2.5-3B-Instruct Q4_K_M + llama.cpp**。先按[本地模型配置](docs/LOCAL_MODELS.md)准备有权使用的权重和本机服务，再打开 <http://127.0.0.1:4173/?planner=3b>。页面上方“两阶段选材”默认使用本机 3B 路线；旧规划入口也保留。

可以尝试：

> 湿地，扫描地表、2组程序碎石、4丛程序低草，种子42，水位0，4×4展示范围。

提取需求后检查 JSON，再检查候选、选择素材，并确认程序素材身份后生成。更改需求会使旧选择失效。需要实拍草或未提供的环境时，应保留缺失提示。

[启动湿地项目.command](启动湿地项目.command) / [停止湿地项目.command](停止湿地项目.command) 是原开发 Mac 的快捷入口，依赖已存在的 Homebrew 路径和已校验权重；新电脑请先用手动配置。脚本不会下载模型或安装运行器。

**3B 使用 Qwen Research License，仅限非商业研究/评估；不能套用 7B 的 Apache-2.0。** 具体条款与模型选择见[许可说明](THIRD_PARTY_NOTICES.md)。

## 项目结构

```text
src/
  selection/       两阶段需求与候选内选材
  planner/         本地模型适配、规划和版本记录
  assets/          资源目录、程序素材与摆放规则
  terrain/         地形、水位及高度代理
  gaussian/        Spark 显示、生命周期与点数预算
  io/              场景包、摘要与 SH3 素材包
scripts/           本机启动器、离线素材准备工具
public/assets/     运行时所需且保留署名的扫描裁片
public/diagnostics/ 已许可的独立诊断素材
tests/            浏览器检查和可重复测试夹具
```

技术栈：TypeScript、Vite、Three.js、Spark、Vitest、Playwright；运行依赖版本由 `package-lock.json` 固定。本地规划 API 随 Vite 开发/预览服务提供，纯静态托管不会自动提供模型接口。

## 当前限制

- 当前只有湿地链路；雪山、雨林与自由跨环境组合尚未实现。每类候选很少，不能据此宣称成熟的通用选材。
- 语言模型会误解否定、来源和水位等表达。JSON 合法不等于意图正确，人工确认是流程的一部分。
- 扫描素材存在柔化、裁边与覆盖限制；SH 范围修正主要影响色调，不能当作锐化或新重建。
- 高度代理和摆放约束是工程近似。Gaussian 数据不自动具备物理碰撞、可编辑物体或物种语义标签。
- 尚未完成大范围场景、动态生态、教学知识热点与学习效果评测，也没有发布云端生成或付费 API 服务。
- 权重、用户存档、原始扫描大包、机器日志和私有实验原件不随源码分发。离线 SH3 variant 包与主页场景 ZIP 是不同格式。
