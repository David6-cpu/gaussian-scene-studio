# 程序基线画质诊断：分发摘要

本页保留资源目录引用需要的技术结论。原始实验记录、机器日志和截图留在开发者本地，未随此源码快照发布；本页不是新增画质验收。

原基线使用低频程序地形、纯色水面、椭球石头和简化植株，缺少真实照片重建细节。采用 Gaussian 作为基元并不会自动带来照片级纹理、几何和光照。

普通浏览已使用最高 2 的设备 DPR；测量保持 DPR 1。更高 DPR 消除额外的采样损失，不能修复缺失细节、岸线柔化或素材形态。采样更密、缩小切向尺度也存在规则网格、漏底等代价，不作为默认修复。

原程序资产只用于兼容旧版。当前扫描地表的范围见 [Riverside 摘要](riverside-integration.md)，实际输入及算法见 [合成素材](../../src/assets/synthetic.ts)。没有通过测试来替代用户画质评价。
