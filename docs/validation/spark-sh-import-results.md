# Spark SH 范围选项：分发摘要

本页汇总 2026-10-04 的本地源码、数值与浏览器验证。原始照片、未入库素材包、机器日志和完整研究证据未随源码快照分发；下列有限结果不作为通用画质承诺。

## 根因与边界

固定 Spark 2.3.1 提交 `2e9c2e74a486b1ba3a31025a22b231b8e4fccde3` 的 [TS 编码器](https://github.com/sparkjsdev/spark/blob/2e9c2e74a486b1ba3a31025a22b231b8e4fccde3/src/utils.ts#L1501)和 [Rust 编码器](https://github.com/sparkjsdev/spark/blob/2e9c2e74a486b1ba3a31025a22b231b8e4fccde3/rust/spark-lib/src/splat_encode.rs#L300)对最大绝对系数的 log2 向下取整；当前解码范围因此可能截断本来可表示的值，例如把 0.75 截为 0.5。项目根据源码和数值复现将其判为指数选取问题，未取得上游维护者确认。

`range-safe` 显式选择足以覆盖输入的指数，保持现有解码格式，仍有 8 位幅值量化、共享指数与小值下溢。它不是 float32 无损方案，也不会修复拍摄、重建或几何的缺陷。输入超出本工具明确范围时拒绝处理。

## 实现和有限验证

- `native` 默认保留六数组字节；显式 `range-safe` 从同一原始 SH3 PLY 重编码高阶系数，几何、DC、透明度和点顺序保持原样。
- 11 项定向测试覆盖范围边界、字段重排、输入身份、格式拒绝、保存/读取和拒绝覆盖；当时全项目 327 单元、8 启动器测试、类型检查与构建通过。
- 在已有 XL 中心 126,807 点裁片的固定浏览器机位，两种模式各自保存后离线重开的画面 RGB 最大差为 0；两模式之间主要是色调差异，不能用作最终画质分数。
- 六数组每分配槽位 96 字节，修正不增点或增加六数组体积；准备阶段要读取原 PLY、另存产物并占额外临时内存。

实现见 [编码器](../../src/gaussian/sh3-range.ts)、[素材包读写](../../src/io/sh3-variant.ts)、[CLI](../../scripts/prepare-sh3-variant.ts)。用法和完整输入约束见 [SH 导入说明](../SH_IMPORT.md)。

输出 `wetland-sh3-variant` 是离线素材包，不是主页场景 ZIP。摘要验证字节完整性，不认证 manifest 语义或素材授权。当前 Riverside、旧存档和默认渲染路径保持原样；接入新内容身份仍需单独验收。
