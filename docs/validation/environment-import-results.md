# 本机 SPZ 环境导入验证

验证日期：2026-10-07。**导入、预览、取消、保存和重开流程通过；真实河岸画质尚未验收。**

## 解决的问题

整场景 Gaussian Splat 需要独立于原有程序场景管理。此次增加“导入环境 · 本机预览”，让用户先检查导入结果，再决定保存，同时保留原场景和相机。

## 已实现

- 读取本地 World JSON、SPZ 和可选请求旁车；校验格式、长度、CRC、点数和内容摘要，不访问元数据中的远程 URL。
- 支持 gzip SPZ v2/v3、SH0–3；上限为 250,000 点、64 MiB 源文件、32 MiB 解压内容。SPZ v4 明确拒绝，不静默减点。
- 预览使用独立画布，暂停并保留旧场景。取消恢复上一环境或原场景；返回恢复原相机、标题和素材署名。
- 独立 IndexedDB 最多保存 8 条、128 MiB。重复保存同版不新增条目，也不覆盖首次保存的相机；损坏记录拒绝保存。保存失败保留预览，并允许下载 `.wetenv` 备份。
- `.wetenv` 保存白名单元数据、相机和原 SPZ 字节；重开再次验证。供应商生成状态与本地视觉结论分开，导入条目均标记为 `visual-pending`。
