## 解决的问题与已实现行为

外加扫描地表需要绑定实际内容、使用许可、地形代理和人工试用结论，不能仅凭一个素材名称进入候选目录。

- 离线准备校验原 PLY、六组数组、许可和 41×41 高度代理，生成绑定内容摘要的素材包；登记还需匹配的独立人工试用记录。
- 每个显式配置最多一块外加地表，启动时冻结目录。网页仅提供受本机 Host/Origin 约束的读取接口，没有任意路径上传或登记入口。
- 目录指纹贯穿候选、模型枚举、独立选材校验和配方；总预算仍为 20 个实例、250,000 个活跃高斯。
- v3 场景 ZIP 自包含地表、许可、代理和布局，离线重开不要求目录仍登记，也不会自动登记素材。选材 JSON v2 则必须匹配已安装的目录和内容；旧历史与 ZIP v1/v2 保持兼容。
- 新场景经准备、激活、实际显示确认后才提交。失败、取消或过期结果回滚；上下文丢失时保留旧 CPU 场景并尝试重建。
