# Riverside 程序资产：分发摘要

本页是资源目录所引用的技术摘要。未发布的本机截图、原始模型响应和诊断包不包含在源码快照中。

草丛、芦苇和三石组合是直接生成 Gaussian 参数的程序资产，不是实拍扫描。资产标注程序身份，保存文件保留内容版本。旧版生成器和存档仍按其对应版本恢复。

布局复用固定种子、边界、水位、间距、15° 坡度和支撑点检查。开启水面时，芦苇还要求接近高度场中派生的水面样点；无法放置时报告数量缺失。这是工程约束，不是生态适生性证据；展示单位不是实测米制。

Riverside 地表仍为固定的 64,949 点 SH3 裁片。每类程序原型 full 4,096 / coarse 1,024 点，场景最多 20 个实例、250,000 个活跃高斯。保存包包含所需资产与实例，重开不需要模型。

独立诊断的 Rock 岩面和 Houseplant 盆栽没有冒充为湿地碎石或植物。当前草丛版本见 [低草摘要](grass-height-refinement.md)，实现见 [river-props.ts](../../src/assets/river-props.ts)。
