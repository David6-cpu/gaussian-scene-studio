# 程序低草：分发摘要

本页是资源目录所引用的技术摘要。原始同机位截图和机器证据留在开发者本地，不随源码快照发布。

`f0-riverside-grass-v2` 使用多处不均匀根区、更短更细且可弯垂的叶片，以及少量颜色变化，替代旧草丛的高大、整齐放射形态。`f0-riverside-grass-v1` 保留原算法供旧存档恢复；芦苇是独立选项。

它仍是程序 Gaussian，不是湿地实拍植物或经鉴定的物种。每个场景共享原型，实例差异来自既有朝向和缩放。根部依赖工程高度代理，不能保证每片叶与真实扫描表面准确接触。

每种原型保持 full 4,096 / coarse 1,024 点；20 实例和 250,000 活跃高斯上限不变。实现和确定性检查见 [river-props.ts](../../src/assets/river-props.ts) 与 [回归测试](../../src/assets/river-props.test.ts)。
